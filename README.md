# SaaP

## Core Product Intent
1. Branches/operating units can run subledgers and local accounting structure.
2. Current-account transactions support subaccount usage for income/expense account trees.
3. Consolidation flows from branch/OU level into legal-entity level.
4. Legal entities consolidate into group-level reporting.

Contracts module intent:
- Contract events should drive accrual-style accounting flows (income/expense accrual posting patterns).
